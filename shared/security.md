# Security requirements

- Use only with explicit authorization on the monitored computer.
- Pairing codes are one-time and expire after five minutes.
- Production must use HTTPS/WSS.
- Add durable per-device authentication before production.
- Require a visible local sharing indicator before screen capture.
- Do not collect passwords, keystrokes, cookies, or unrelated personal data.
- Do not implement hidden recording or stealth persistence.
- Add audit logs and admin authentication before production.
